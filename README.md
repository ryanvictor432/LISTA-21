## 💻 Sobre o Projeto
Esta é uma aplicação desenvolvida em **Blazor (.NET)** que tem como objetivo consumir o endpoint `https://jsonplaceholder.typicode.com/users` da API pública *JsonPlaceHolder*.

O algoritmo realiza uma requisição HTTP para obter uma lista de utilizadores e imprime os dados específicos da **primeira pessoa** retornada diretamente no ecrã da consola do navegador.
